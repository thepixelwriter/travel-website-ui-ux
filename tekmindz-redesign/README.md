# TekMindz redesign

A multi-page, vanilla HTML/CSS/JS redesign of [tekmindz.com](https://www.tekmindz.com/). Vite is used only for local development and production bundling; there is no React or Angular dependency.

## Run locally

```bash
npm install
npm run dev
```

The route-aware content layer preserves the original site's key URL families and shared navigation. Live CDN imagery is intentionally reused from the source site.
